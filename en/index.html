03 / Flagship project

SAYOON — a voice agent that calls patients.

An autonomous AI voice agent that runs follow-up call campaigns for tuberculosis patients: treatment adherence, side effects, appointments. Institutional lead: IRESSEF, Tambacounda health district. Guiding principle: in production, no medical or patient-identifying data goes through a third-party cloud service. The system is in pre-deployment evaluation, tested on synthetic patient data.

2026 — ongoing · pre-deployment evaluation

  1. 01CallTwilio gateway for the pilot · hosted telephony planned for production

  3. 03DecisionLocal LLM via Ollama · strict JSON output, downstream validation

The first prototype relied on Gemini (listening, decision and synthesis) to validate the dialogue quickly. Measuring every stage showed that the speech-synthesis tail weighed most on the p90; caching the fixed prompts cut a turn from 6.5 s to 3.7 s. These measurements are the baseline for the hosted pipeline, which keeps patient data on the server.
